# SamsungGameDevSprintOne
Доработка игры спринта 1

Игровая логика вынесена в отдельные классы. Game - игровой цикл, бои, сложность, GameField - хранение и отрисовка поля, проверка/выполнение ходов. 

Объекты на поле реализованы в виде классов с общим интерфейсом Entity. 

record Problem для описания математической задачи

Поле хранится как двойной массив из Entity, то есть хранит сами объекты, а не только изображения.

Позиции монстров и замка хранятся в самих объектах. 

Два типа монстров: маленький (эмодзи кота) и большой (эмодзи вампира). Количество монстров вычисляется от размера поля в пропорции 2:3 (большие:маленькие) (количество совпадает с образцом, пропорции взяты с рисунка ТЗ).  Генерация монстров вынесена в generateMonsters с защитой от бесконечного цикла (могу переделать на обход доски). Монстр не может занять позицию замка или игрока.

Сложность задачи: 1 — сложение, 2 — вычитание, 3 — умножение, 4 — деление нацело, 5 — НОК (алгоритм НОК найден готовый). Добавлена валидация сложности при вводе (вне 1–5 ставится 3). При неверном ответе жизнь теряется; при 0 жизней игра завершается.

Добавлена проверка хода игрока на выход за границы поля.
